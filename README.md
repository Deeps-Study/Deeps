# Deeps

### "흩어진 지식을 깊이 있게, 우리만의 퀴즈 스터디 플랫폼: Deeps"
[딥스 바로가기](https://deepstudy.cloud)

## 기획 배경 및 프로젝트 개요

온라인 스터디가 활성화되면서 많은 모임이 카카오톡과 노션을 기반으로 진행되고 있습니다. 
하지만 기존 툴들은 학습 전용 플랫폼이 아니기에 다음과 같은 구조적 한계를 지닙니다.

- **파편화된 기록과 관리의 복잡함** <br>
카카오톡은 대화 속에 학습 인증이나 퀴즈 기록이 쉽게 묻히고, 노션은 참여하는 스터디가 늘어날수록 워크스페이스와 페이지가 난립해 한 곳에서 통합 관리하기 어렵습니다.
- **출제자와 풀이자 역할 분리의 한계** <br>
노션은 문서 특성상 출제자가 등록한 정답과 해설이 풀이자에게 사전에 노출되기 쉬워 실질적인 테스트 환경을 구축하기 어렵습니다.
- **학습 인터랙션 부재**<br>
지정된 시간에 맞춰 답안이 자동 공개되거나 힌트를 제공하는 등 퀴즈 운영이 불가능합니다.

## 주요 기능

- **스터디 생성 및 참여 관리**: 비밀번호 기반 비공개 스터디, 인원 제한, 기간 설정
- **딥스(문제) 출제 및 에디터**: Tiptap 기반 리치 텍스트 에디터, 출제자/풀이자 화면 분리, 최초 제출 후 수정 잠금(edit-lock)
- **퀴즈 풀이 및 피드백**: 스터디원들의 문제 풀이, 정답 확인 및 해설 공유
- **홈/대시보드**: 내 스터디 목록 및 학습 진행 현황 확인

## 디자인 및 UI 시스템

- **Color System**: Deeps 메인 포인트 컬러(# 149F37)
